### 为什么把相位机抽出来共用

练习 4 和练习 5 的**协议必须逐字节一致**：留出点的存在意义就是「拿去和之前的数据比」，
如果两次的稳定时长、采样间隔、冷却时长有任何差别，**那个差别会伪装成模型误差**。
共用同一个 `sweepStep` 是让这件事在结构上不可能出错的办法。

两个入口函数各自只有两行：

```cpp
void Controller_c::testSaturation(Robot_c &robot, unsigned long now) {
  sweep_uses_gain_levels = false;   // 走 60–200 的 ladder
  sweepStep(robot, now);
}

void Controller_c::testGain(Robot_c &robot, unsigned long now) {
  sweep_uses_gain_levels = true;    // 走 GAIN_PWM_LEVEL_* 这两个留出档位
  sweepStep(robot, now);
}
```

### 3.1 留出点的选择

| `GAIN_PWM_LEVEL_0` | **100** | **区间中段**。检验的是插值能力，也就是"最容易对"的那一类 |

### 7.5 怎么报告结论

课程要的最终形态是：

> **"a gain estimate tied to one stated wheel, direction, operating range, and set of physical conditions, plus residual and held-out evidence"**

所以结论句必须同时说清四件事，例如：

> 左轮正转、空载（轮子悬空）、PWM 40–170、速度单位 counts/s：
> **G = 14.0 counts/s per PWM（= 3.94 mm/s per PWM），c = −94 counts/s**。
> 区间内残余在 ±0.4% 内且无系统性走向；两个留出点（100、160）的预测误差
> （−2.0 和 +5.0 counts/s）都小于重复测量的标准差（±10 counts/s）。

**几条必须交代的**：

1. **G 是"操作增益"，不是电机的固有常数。** 课程原文：
   *"It is therefore more correct to refer to G as an **operational gain** (correct within specific operational constraints). The gain we will determine is not intrinsic to the motor."*
   —— 换负载、换地面、换电池，G 都会变。
2. **别把 G 当成通用常数套到所有情况。** 课程第 9 步要求考虑另一轮、另一方向是否要单独拟合。
3. **区间边界要说清**：下界 40 来自死区（(30, 40]），上界 170 来自饱和拐点（~171）。
4. **如果有离群点**：课程允许为"追求好的线性拟合"排除异常点，但要求**记下原始选择并说明改动的依据**。
   而且如果是做实验报告而不是拟合，离群点应当保留。

## 附录：为什么这个练习重要

练习 3–5 合起来，就是一个电机在**可用区间**内的完整行为模型：

```
速度
  ↑
  │                    ┌─────────────  ← 练习 4：饱和，加大指令没用
  │                ┌───┘
  │              ┌─┘                  ← 练习 5：这一段用 ω̂ = G·u + c 描述
  │            ┌─┘                        G 就是这条线的斜率
  │          ┌─┘
  │        ┌─┘
  │    ┌───┘
  │────┘                              ← 练习 3：死区，指令太小转不起来
  └───┬─────────────────────────→ PWM
      ↑
```

**为什么 G 是控制器里最直接要用的数**：任何比例控制器的增益都得和它配合。
知道 G 之后你才能算出"要多大的 PWM 才能让轮子跑到想要的速度"，
也才知道**这个换算在多大范围内成立**——超出 40–170 它就不成立了。

而在数字孪生（Phase 2）里，G 和 c 就是仿真模型里那两行参数。
**填错了，仿真的机器人就和真机对不上**，所有在仿真里调出来的控制器参数都得重来。

这个练习最容易做废的三个地方：

1. **把练习 3 的整轮均值直接拼进来** → 低端整体偏低约 15%，伪造出一个假斜率
2. **留出点已经被测过还拿来当"预测检验"** → 自己考自己，不算证据
3. **没写清楚 G 的适用范围** → "增益是 14" 这句话单独拿出来是错的
